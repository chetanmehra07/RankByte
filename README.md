# RankByte

An AI-powered adaptive platform for practicing **System Design** and **Bug-Fixing challenges** through progressive level-based learning.

Most coding platforms mainly focus on DSA practice, but there are very few platforms dedicated to improving real-world debugging and system design thinking. RankByte aims to bridge that gap by dynamically generating AI-powered challenges and adapting difficulty based on user performance.

Built using React, FastAPI, PostgreSQL, SQLAlchemy, Groq APIs, and modern cloud deployment infrastructure.

---

## ✨ Features

- Adaptive difficulty progression based on user performance
- Real-time code execution and debugging workflow
- XP, streaks, and leaderboard-based gamification
- Secure Clerk JWT authentication
- Personalized user progress tracking
- Fast and responsive full-stack architecture
